## 一、服务内容与形式

1. 本应用是一款**个人记账工具**，提供账单记录、多账本管理、预算统计、收支图表、账单导出，以及图片识别、语音识别、AI 自然语言记账、桌面小组件等功能。
2. 本应用的核心功能在**设备本地**运行，除可选的华为账号登录与云同步外，**无需注册任何账号**即可使用。
3. 云同步为可选功能，由华为 AppGallery Connect 提供（华为账号服务、认证服务与云数据库），需你主动登录并开启。
4. 本应用**当前全部功能免费**，不设付费墙、不提供应用内购买项目。详见第九条。
5. 本应用为工具型软件，**不提供任何形式的理财建议、投资建议或记账代理服务**，不代你保管资金，不涉及任何资金流转与支付结算。
