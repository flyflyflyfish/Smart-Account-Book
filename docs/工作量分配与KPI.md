## 3. 提交质量

- 统一 `类型(范围): 详细中文说明` 格式，全文中文不混用；
- 单一职责粒度：一个 commit 一件事（可查 `git log --stat main`）；
- 关键 commit 附量化说明（如准确率、命中数、parity 规模）。

## 4. 度量说明

- 行数含自动生成资源的增删，仅作工作量参考，不作为唯一标准；
- 评审与联调（代码走查、真机验收、演示准备）未计入 git 度量，由两名成员共同完成。
