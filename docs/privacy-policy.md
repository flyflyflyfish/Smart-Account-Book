## 一、引言

智能记账助手是一款个人记账工具。我们深知账单与收支数据属于高度私密的信息，因此本应用以"**本地优先、最小收集、不追踪**"为设计原则：

- 你的账单数据**默认只保存在你自己的设备上**；
- 我们**不出售、不共享、不分析**你的账单数据，也**不集成任何广告、统计、用户画像或行为追踪类 SDK**；
- 需要联网的功能（云同步、云端识别）均由你主动开启，未开启时本应用可完全离线使用。

请你仔细阅读并充分理解本政策后使用本应用。若你不同意本政策内容，请停止使用本应用。

## 二、我们收集哪些信息

### 2.1 必要信息（不提供则无法使用对应功能）

| 信息类型 | 具体内容 | 收集时机 | 存储位置 |
|---|---|---|---|
| 账单数据 | 金额、收支类型、发生时间、分类、商家名称、备注、所属账本 | 你手动录入，或经你确认后由识别功能生成 | 本机数据库；登录并开启云同步后备份至华为云数据库 |
| 应用设置 | 预算额度、提醒时间、账本名称、界面偏好 | 你主动设置时 | 同上 |
| 语音内容 | 你说出的记账语句（如"昨天午饭二十块"） | 仅在你主动点击语音记账时采集 | **不存储、不上传**，在设备端转为文字后即丢弃音频 |
| 图片内容 | 你拍摄或从相册选择的票据图片 | 仅在你主动使用拍照/相册识别时读取 | **不存储**于服务器；仅在设备端识别，或在你启用云端识别时由设备直接发送给你配置的服务商 |

### 2.2 可选信息（你主动授权后才收集）

| 信息类型 | 具体内容 | 用途 | 未授权的影响 |
|---|---|---|---|
| 华为账号标识 | 华为账号匿名标识（uid）；昵称与头像仅在你主动授权后获取 | 标识云端数据的归属，实现多设备同步；在该设备上展示你的头像昵称 | 无法使用云同步，本地记账与统计功能不受任何影响 |
| 端侧学习记忆 | "商家名称 → 收支分类"的对应关系 | 提升下次自动分类的准确率 | 无影响，仅识别准确率略低 |

### 2.3 我们**不收集**的信息

我们**不会**收集、申请或读取以下信息：

- 通讯录、短信、通话记录、日历、剪贴板；
- 精确或粗略地理位置；
- 已安装应用列表、软件列表；
- IMEI、MAC 地址、设备序列号等可用于**跨应用追踪**的硬件标识符；
- 身份证件、人脸、指纹、声纹等生物识别信息；
- 银行卡号、支付密码等金融账户凭据。

本应用**不进行用户画像、不用于广告推送、不向任何第三方出售数据**。

## 三、关于敏感个人信息的特别说明

你的收支明细、消费习惯与预算设置，能够反映个人财务状况与生活轨迹，属于**敏感度较高**的个人信息。对此我们采取以下强化措施：

1. **默认不离开设备**：未登录或未开启云同步时，全部账单数据仅存在于本机数据库；
2. **归属隔离**：云端数据以你的华为账号标识（uid）作为唯一归属键，与其它用户的数据在逻辑上严格隔离，你无法访问他人的数据，他人也无法访问你的数据；
3. **传输加密**：所有网络请求均通过 HTTPS/TLS 加密通道传输；
4. **密钥隔离**：你填写的第三方大模型 API Key 仅保存在本机，不上传云端、不经过我们转发，在界面与日志中均以掩码显示；
5. **最小化处理**：识别失败或你放弃保存的临时数据不会被留存。

## 四、系统权限与系统能力调用

本应用遵循"**用不到就不申请、只在功能触发时调用**"的原则。应用实际声明申请的权限如下：

| 权限名称 | 对应功能 | 拒绝授权的影响 |
|---|---|---|
| `ohos.permission.INTERNET`（网络） | 云同步、你自行配置的云端大模型识别 | 无法云同步与云端识别；本地记账、统计、导出全部正常 |
| `ohos.permission.MICROPHONE`（麦克风） | 语音记账，将语音转为文字 | 无法使用语音记账，其余功能不受影响 |
| `ohos.permission.PRINT`（打印） | 将账单导出为 PDF 并调用系统打印服务 | 无法打印导出，其余功能不受影响 |

此外，以下能力通过**系统安全控件或系统弹窗**提供，本应用**不申请、也无法直接获取**对应数据：

- **通知**：预算提醒与周期账单提醒通过系统通知服务发送，首次使用时由系统弹窗向你征求同意，你可随时在系统设置中关闭。本应用**未集成**任何第三方推送（Push）服务，提醒完全在设备本地计算与触发，不联网、不上传设备标识。
- **相机**：拍照识别时调用**系统相机**（cameraPicker），由系统界面完成拍摄，本应用只能获取你当场确认拍摄的这一张照片，无法访问相册中的其它图片。
- **相册**：选择图片时调用**系统图片选择器**，由你逐次勾选，本应用只能获取你主动选中的文件，**无权浏览、检索你的相册**。

**拒绝任何一项授权，都不影响其它功能的正常使用。**

## 六、云端大模型识别（由你自行配置，默认关闭）

本应用的 AI 识别能力默认使用**设备端离线识别**。云端识别属于可选增强能力，**必须由你手动填写自己的 API Key 后才会启用**。

1. **数据流向**：启用后，待识别的票据图片或记账文本将由**你的设备直接发送**至你所选择的服务商接口，**不经过我们的服务器**，我们无法查看、记录或留存这些内容；
2. **可选服务商**：目前内置豆包（火山引擎）、通义千问（阿里云）、智谱 GLM、DeepSeek、Kimi（月之暗面）等国内服务商的官方接口；上述接口地址与请求内容受各服务商自身的用户协议与隐私政策约束；
3. **自定义服务商**：应用支持你填写第三方的 OpenAI 兼容接口。若你填写的服务器位于**中国大陆境外**，则相应数据将由你自行发往境外，构成数据出境行为，请你在使用前自行确认该服务商的数据处理规则与合法性；
4. **费用与责任**：云端识别产生的接口费用由你与该服务商直接结算，与本应用开发者无关；
5. **随时关闭**：你可在"设置 → 模型设置"中清除 API Key 或切换回端侧识别，关闭后不再发生任何外发请求。

## 七、信息的存储

1. **存储地点**：你的个人信息存储于**中华人民共和国境内**（设备本地存储，以及华为 AppGallery Connect 位于中国境内的云数据库节点）。我们**不会**将你的个人信息传输至境外。若你主动配置境外大模型接口，参见第六条第 3 项。
2. **存储期限**：
   - **本地数据**：保留至你删除对应账单或卸载本应用。卸载应用后本地数据即刻删除，无法恢复；
   - **云端数据**：保留至你主动删除（单条或全部）或停止使用云同步。你执行"清空全部账单数据"后，我们将在 **15 个工作日**内完成云端数据及相关缓存的删除；
   - **API Key**：仅存储于本机，你清除后立即失效，我们不保留任何副本。
3. **安全措施**：传输层采用 HTTPS/TLS 加密；云端数据以账号标识隔离并受华为云安全体系保护；应用内不记录明文密钥。
4. **安全事件处置**：若不幸发生个人信息泄露、篡改或丢失，我们将按法律法规要求，及时以应用内通知或邮件方式告知你事件情况、可能的影响、我们已采取的处置措施及你应有的防范建议，并按规定向监管部门报告。

## 八、信息的共享、转让与公开披露

1. **我们不会出售你的个人信息**，也不会为商业目的向任何第三方提供你的账单数据。
2. **共享**：仅在以下情形下存在必要的数据处理：
   - 华为账号服务、AGC 认证与云数据库：为提供登录与同步功能所必需，处理范围见第五条；
   - 你自行配置的大模型服务商：仅在你启用云端识别时，由你的设备直接发送待识别内容；
   - 法律法规要求、司法机关或行政机关依法定程序要求提供的情形。
3. **转让**：本应用不会将你的个人信息转让给任何公司、组织或个人。若发生合并、分立、收购等情形导致主体变更，我们将要求承接方继续受本政策约束，否则将重新征求你的同意。
4. **公开披露**：我们不会公开披露你的个人信息，法律法规另有规定的除外。
5. 除上述情形外，本应用**不向任何第三方提供数据接口，也不接入任何数据交易、联合建模或广告投放平台**。

## 九、你的权利与行使方式

依据《中华人民共和国个人信息保护法》，你对自己的个人信息享有以下权利。我们承诺在收到你的请求并核验身份后 **15 个工作日**内予以答复和处理。

| 权利 | 如何行使 |
|---|---|
| **查阅、复制** | 应用内"账单"页可查看全部记录；"设置 → 数据管理"支持导出账单（CSV/PDF） |
| **更正、补充** | 点击任一笔账单即可编辑金额、分类、时间、备注等全部字段 |
| **删除** | "设置 → 隐私与安全 → 数据管理 → 清空全部账单数据"可一次性删除本机与云端的全部账单及账本；也可逐条删除。删除后不可恢复 |
| **撤回同意** | "设置 → 隐私与安全"中可关闭云同步、撤回云端识别授权、清除端侧学习记忆；系统设置中可关闭麦克风、通知等权限 |
| **退出登录 / 停止云同步** | "设置 → 账号"中退出华为账号，退出后本应用不再同步任何数据 |
| **注销（删除账号关联数据）** | 本应用不设立独立注册账号体系，你的身份由华为账号提供。执行"清空全部账单数据"并退出登录，即完成本应用侧的账号数据清除；如需注销华为账号本身，请通过华为账号中心办理 |
| **获取政策副本** | 应用内"设置 → 隐私政策"随时可查看本政策全文 |

如你希望行使上述权利但无法通过应用内功能完成，可发送邮件至 **3855757949@qq.com**，说明你的华为账号标识与具体请求，我们将在核验后处理。

## 十、未成年人保护

1. 本应用主要面向成年人，**不面向未满十四周岁的儿童**设计，也不会主动收集儿童的个人信息。
2. 若你是未满十四周岁的儿童，请在监护人的陪同与同意下使用本应用；监护人应妥善保管设备与华为账号。
3. 若你是监护人，发现未成年人在未经你同意的情况下向我们提供了个人信息，请通过第九条的联系方式告知，我们将在核实后**尽快删除**相关数据。
4. 我们不会将未成年人信息用于任何营销目的。
