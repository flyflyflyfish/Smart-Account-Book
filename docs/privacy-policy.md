## 一、引言

智能记账助手（以下简称"本应用"）是一款个人记账工具。我们非常重视你的个人信息与隐私。本应用以"本地优先"为设计原则：你的账单数据默认仅保存在你的设备本地，我们不出售、不共享、不分析你的任何数据，也不集成任何第三方统计、广告或追踪 SDK。本政策说明本应用收集哪些信息、如何存储与使用这些信息，以及你所拥有的控制权。请你仔细阅读并充分理解本政策后使用本应用。

## 二、我们收集的信息

1. **账单信息**：你手动录入或通过识别功能生成的账单内容，包括金额、时间、商家、分类与备注。账单数据默认保存在本机数据库中。
2. **账号标识**：当你选择登录华为账号以启用云同步时，我们会取得你的华为账号匿名标识（uid），仅用于标识云端数据的归属，不用于其他用途。本应用不会获取你的华为账号密码；昵称与头像仅在你主动授权后获取，且仅用于本应用界面展示。
3. **学习记忆**：为提升识别准确率，本应用会在本机记录"商家—分类"的学习记忆，你可在"设置 → 隐私与安全"中随时清除。
4. **语音与图片**：语音识别在设备端完成，录音内容不会存储，也不会上传（除非你配置了云端大模型接口）；图片经系统相册选择器或相机拍摄获取，默认仅在本设备端识别处理。
5. 我们**不收集**你的通讯录、短信、位置信息，也不收集与记账无关的任何个人敏感信息。

## 三、信息的存储

1. **本地优先**：所有账单数据首先保存在本机数据库，未登录账号时数据不离开你的设备；卸载应用即随之删除本地数据。
2. **云端同步**：登录华为账号后，你的账单、账本与设置将经加密通道同步到华为云数据库（AppGallery Connect），用于在你登录同一账号的设备间保持数据一致。云端数据归属于你的华为账号，并以你的账号标识与其他用户的数据严格隔离。你可随时退出登录以停止云同步。
3. **识别服务密钥**：你在模型设置中填写的第三方大模型服务 API Key 仅保存在本机，不上传云端，也不经我们转手；密钥在界面与日志中均以掩码显示。
4. 本应用不对任何第三方提供数据接口。

## 四、权限用途

本应用遵循最小权限原则，仅在对应功能使用时申请权限：

1. **网络**：用于云同步（AppGallery Connect 云数据库）及你自行配置的大模型接口访问。拒绝授权仅影响云同步与云端识别，本地记账不受影响；
2. **相机**：用于拍摄账单票据以识别账单。拒绝授权将无法使用拍照识别；
3. **麦克风**：用于语音记账。拒绝授权将无法使用语音记账，其余功能不受影响；
4. **通知**：用于预算提醒与周期账单提醒。拒绝授权将收不到相关提醒；
5. **照片访问**：用于从相册选择票据图片进行识别。拒绝授权将无法使用相册识别；
6. **打印**：用于导出账单打印。拒绝授权将无法使用打印导出。

拒绝授权不影响其他功能的正常使用。

## 五、第三方服务

1. **华为账号服务（Account Kit）**：提供账号登录与身份标识；
2. **华为云数据库（AppGallery Connect）**：登录后提供端云数据同步；
3. **大模型识别服务**：当你启用云端识别时，账单图片或文本将由你的设备直接发送至你自行配置的服务商（如字节跳动豆包、阿里通义千问、智谱 GLM、DeepSeek、月之暗面 Kimi 等）进行识别，该过程不经过我们的服务器，数据流转由你与服务商之间的协议约束。

## 六、信息的删除与控制

1. 你可在"设置 → 隐私与安全 → 数据管理"中**清空全部账单数据**，该操作会同时删除本机与云端的全部账单及账本记录，不可恢复；
2. 你可清除学习到的商家分类记忆；
3. 你可随时撤回云端识别授权、退出华为账号登录并停止云同步。

## 七、未成年人保护

本应用不面向未满十四周岁的儿童。监护人应为未成年人妥善保管设备与账号，如发现未成年人在未经同意的情况下使用本应用，可联系我们删除相关数据。

## 八、政策更新

我们可能适时修订本政策。重大变更会通过应用内提示等方式通知你。更新后你继续使用本应用，即视为接受修订后的政策。
