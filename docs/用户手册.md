# 用户手册

记账助手是一款 HarmonyOS 个人记账应用：拍照即可记账，全部数据默认保存在本机，可选登录华为账号开启端云同步。

## 快速上手

1. 安装应用后进入首页，默认显示本月支出 / 收入总览与账单列表。
2. 点击首页右下角 **+** 悬浮按钮记账：
   - **手动添加一笔**：进入记一笔页面；
   - **拍照识别**：调起相机拍摄小票 / 账单；
   - **AI 助手**：对话或语音记账。
3. 不登录、不配置任何云端服务，本地功能全部可用。

## 记账方式

### 手动记账

记一笔页面：选择 **支出 / 收入** 页签 → 点分类（可左右滑动查看全部，支持自定义分类）→ 用自定义键盘输入金额 → 选择日期与支付时间 → 填写备注 → 保存。

- 金额上限 ¥9,999,999.99，超出会提示。
- 同商家再次记账时，会优先套用上次确认过的分类（学习记忆）。

### 图片识别记账（核心功能）

从 **+** 菜单选择 **拍照识别**，或从相册一次最多选 9 张账单截图：

1. **识别**：端侧 OCR + 自训练小模型在本地完成识别，无需联网；批量图片并行识别，逐张显示进度。
2. **确认**：识别结果以草稿卡片列出（金额、商家、支付时间、分类），逐笔核对：
   - 点卡片展开编辑金额 / 分类 / 时间 / 备注；
   - 勾选决定哪些入账，默认全选；
   - 疑似重复的账单会标注「疑似重复」，按需取消勾选；
   - 漏识别的交易可点「手动添加一笔」补录；
   - 对端侧结果不满意可单张「回退云端大模型」重新识别（需已配置云端服务）。
3. **入账**：点「入账」按钮批量保存，按钮变为「正在入账…」直至完成。

识别失败的图片会显示原因，可单独重试。

### AI 助手 / 语音记账

设置区进入 **AI 助手**：文字或语音描述（如「昨天午饭花了 35」），助手解析为账单草稿确认入账，也可询问消费分析；底部快捷提问一键发送常见问题。

### 账本记账

1. **外观 → 首页统计** 中可将底部第二页签切换为 **账本**。
2. 账本页支持新建 / 长按改名删除账本。
3. 账本内记账与主账单相互独立：
   - 账本内点 **+** 直接记入该账本；
   - **从现有账单导入**：按时间段 / 类型 / 分类筛选主账单勾选复制，已导入过的不会重复；
   - **图片识别入账**：识别入账时同步复制进该账本。
4. 「同步记入主账单」开关（外观 → 首页统计 → 账本区，或识别页内）决定账本记账是否同时计入首页统计。

### 周期账单

适合房租、会员等固定收支：设置每天 / 每周 / 每月周期，到点自动记入并发送系统通知，也可手动一键记入当期。

### 账单文件导入

支持 **支付宝** 账单 CSV（GBK / UTF-8）与 **微信** 账单 CSV / XLSX：导入时自动智能分类、查重（重复账单跳过），批量入库。

## 账单管理

- **首页列表**：按日期分组展示，点击任一笔进入编辑；长按可进入批量管理（多选删除）。
- **搜索**：首页右上角搜索入口，支持关键字、时间段、收支类型、分类组合筛选，结果按日分组。
- **统计**：月账单 / 年账单切换，按日或按分类视图，点分类下钻查看明细；页头支持自定义时间段时间选择弹窗。
- **预算**：设置月度消费额度，超支时弹窗与系统通知提醒。
- **导出**：账单导出为 Word（.docx）/ PDF，支持本月 / 上月 / 近三月 / 本年，可预览与分享。

## 个性化

### 外观

设置 → **外观**：

- **主题**：松绿 / 暖橘 / 清爽蓝 / 雅紫 / 极简灰 / 曜石灰 6 套预设 + **自定义主题**（色环取色或输入色值，色相 / 饱和度 / 明度微调，迷你界面实时预览；保存后自动派生浅 / 深两套配色）。
- 深浅色模式、字体大小、光感调节。
- 所有外观设置即时生效，小组件同步跟随。

### 桌面小组件

支持 **2×2 小卡**（今日支出 / 收入）与 **2×4 大卡**（今日本月口径切换 + 三快捷入口）：

- 右上角 **+** 展开菜单：手动添加 / 拍照识别 / AI 助手（或账本，随底部页签配置）；
- 双击卡片主体可打开应用首页；
- 配色跟随应用主题。

## 数据与同步

### 端云同步（可选）

1. 设置中登录 **华为账号**（AGC 认证服务）。
2. 登录后自动开启：
   - **账单**：按主键双向合并，`create_time` 新者胜，换机重装不丢数据；
   - **设置与自定义分类**：全量同步，分类并集合并（双方新增都保留）；
   - **商家→分类学习记忆**：识别习惯跨设备保留；
   - **删除墓碑**：防止已删账单在其他设备「复活」。
3. API Key 等敏感配置仅存本机，不上云。

### 识别引擎配置

设置 → **识别设置**：

- **端侧识别**：开关端侧 OCR / 端侧账单模型（默认开，离线可用）；
- **云端识别**：开启后可配置多服务商（接口地址 / API Key / 视觉模型），支持「测试连通性」；可保存多套配置一键切换。
- 首次上传图片前会单独请求云识别授权。

## 常见问题

| 问题 | 说明 |
| ---- | ---- |
| 不联网能用吗？ | 能。手动记账、图片识别（端侧）、统计、账本、导出全部离线可用；仅云端大模型识别与云同步需联网。 |
| 图片会被上传吗？ | 默认仅本地处理。只有开启云端识别并授权后，识别时才将图片发给你自己配置的大模型服务。 |
| 换手机数据怎么迁移？ | 登录华为账号开启云同步，新设备登录后自动合并拉取。 |
| 识别错了怎么办？ | 确认页可逐笔修改；修改分类会记入学习记忆，下次同商家自动套用。 |
| 金额输不了更多位？ | 单笔上限 ¥9,999,999.99，防止误输导致统计错乱。 |
